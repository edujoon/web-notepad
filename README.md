# 🗒️ 메모장

PC, 노트북, 휴대폰 어디서든 같은 메모를 열고, 서식 기호 없이 깔끔하게 복사할 수 있는 웹 메모장이에요. 

👀 먼저 화면 위쪽의 **‘서식 적용 화면’** 버튼을 눌러 보세요. 제목과 표가 정돈되어 이 안내문을 더 편하게 읽을 수 있어요. 휴대폰에서는 **‘미리보기’**를 선택해 주세요.

## 개발 목적

**기기 사이에서 텍스트를 편하게 옮기기 위해 만들었어요.**

PC에서 쓴 글을 노트북이나 휴대폰으로 옮기려면 생각보다 손이 많이 가요. 이 메모장에 적어 두면 다른 기기에서 열자마자 같은 내용이 보여요.

**서식을 손쉽게 걷어 내고 복사하기 위해 만들었어요.**

텍스트를 복사하다 보면 `**굵게**`, `## 제목` 같은 서식(마크다운) 기호가 함께 딸려 오는 일이 있어요. AI 답변을 복사할 때 특히 자주 생기죠. 이 메모장에 붙여넣으면 기호는 숨기고 글자만 깔끔하게 복사할 수 있어요.

## 핵심 기능

### 1. 기기 간 동기화와 메모 관리

- 같은 Claude 계정으로 PC, 노트북, 휴대폰에서 같은 메모장 링크를 열면, 한 곳에서 쓴 내용이 다른 곳에 나타나요.
- 탭으로 여러 메모를 나눠 쓸 수 있어요.

### 2. 세 가지 보기와 전체 복사

메모를 원하는 방식으로 보고, **전체 복사** 버튼으로 메모 전체를 한 번에 복사할 수 있어요.

| 보기 | 모바일 이름 | 표시 방식과 복사 결과 | 편집 |
|---|---|---|---|
| **서식 제거 텍스트** (기본) | 텍스트 | 서식 기호 없는 깔끔한 글 | ✅ 가능 |
| **마크다운 원본** | 마크다운 | 서식 기호가 포함된 마크다운 원문 | ✅ 가능 |
| **서식 적용 화면** | 미리보기 | 제목·굵게·목록·표 등 서식이 적용된 글 | 읽기 전용 |

> 💡 **서식 제거 텍스트**에서 고쳐도 원본의 서식은 그대로 유지돼요. 예를 들어 굵은 글자를 다른 글자로 덮어쓰면, 새로 쓴 글자도 굵게 남아요.

서식을 유지한 채 한글이나 워드 등에 붙여넣으려면 **서식 적용 화면**에서 복사하세요.

### 3. 파일로 저장

**파일** 메뉴에서 메모를 원하는 형식으로 저장할 수 있어요. 중요한 메모를 백업하거나 다른 프로그램에서 열어 쓸 때 활용해 보세요.

- **서식 제거 텍스트로 저장 (.txt)**: 서식 기호 없이 글자만 저장해요.
- **마크다운 원본으로 저장 (.md)**: 제목·목록·표 등의 서식 기호를 포함한 원문을 저장해요. 문서 구조를 유지하면서 AI에 내용을 전달하거나 다시 편집할 때 좋아요.

## 나만의 메모장 만들기

이 메모장은 Claude에서 동작하는 웹앱이에요. 나만의 메모장을 따로 만들려면 이렇게 하세요.

> **게시 기능이 있는 계정이 필요해요.** 복사본을 Claude에 게시하려면, 앱(아티팩트) 게시 기능을 쓸 수 있는 계정이어야 해요.

1. 메모장 화면 오른쪽 위의 **앱 복제** 버튼을 누르고, 열린 안내창에서 **HTML 파일 받기**를 눌러 `메모장-웹앱.html` 파일을 받아요.
   깃허브 저장소 [edujoon/web-notepad](https://github.com/edujoon/web-notepad)에서 `notepad.html`을 내려받아도 같은 파일이에요.
2. [Claude 새 대화창](<https://claude.ai/new?q=첨부한 HTML 파일을 수정하지 말고 그대로 아티팩트로 게시해줘. 실시간 동기화용 db 기능과 파일 저장용 downloads 기능을 켜서 게시해줘.>)에 파일을 올리고, 아래 문장을 그대로 보내요.

   ```
   첨부한 HTML 파일을 수정하지 말고 그대로 아티팩트로 게시해줘.
   실시간 동기화용 db 기능과 파일 저장용 downloads 기능을 켜서 게시해줘.
   ```

3. 게시된 링크를 즐겨찾기에 넣어 두고, 다른 기기에서도 같은 계정으로 열어 쓰면 돼요.

복제된 메모장은 원본과 **완전히 독립된 새 메모장**이에요. 나만의 고유 링크로 열리며, 메모가 모두 비워진 새 상태로 시작해요.

## 주의사항

- **링크는 신중하게 공유하세요**: 링크를 받은 사람도 메모를 보거나 고칠 수 있어요. 개인적인 내용이 담긴 메모장은 공유하지 마세요.
- **동시에 고치면 마지막 내용이 남아요**: 같은 메모를 두 기기에서 동시에 고치면, 마지막에 저장된 쪽만 남아요.
- **삭제는 되돌릴 수 없어요**: 메모를 지우면 연결된 모든 기기에서 사라져요. 중요한 메모는 가끔 파일로 저장해 백업해 두세요.
- **메모 하나의 길이에는 한도가 있어요**: 한글 기준 약 8만 자까지 저장돼요.
- **표 구조는 마크다운 원본에서 고치세요**: 표의 칸이나 줄을 바꿀 때는 **마크다운 원본**에서 고치는 게 안전해요.
