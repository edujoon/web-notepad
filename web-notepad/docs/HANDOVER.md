# 메모장 웹앱 인수인계 문서

작성일: 2026년 9월 23일 · 만든 사람: JOON (eduedujoon@gmail.com) · 라이선스: MIT

이 문서는 실시간 동기화 메모장 웹앱을 이어받아 작업할 사람을 위한 안내예요. 앱을 고치거나 다시 게시하기 전에 **"수정할 때 반드시 지킬 것"** 항목을 먼저 읽어 주세요.

## 1. 무엇을 만들었나

마크다운 기호가 섞인 글을 깔끔하게 보고 복사하며, 여러 기기에서 같은 메모를 이어 쓰는 웹 메모장이에요. Claude의 아티팩트로 게시해서 동작해요.

**세 가지 보기**

| 보기 | 모바일 이름 | 내용 | 편집 |
|---|---|---|---|
| 서식 제거 텍스트 (기본) | 텍스트 | 마크다운 기호를 숨긴 글자만 | 가능 |
| 마크다운 원본 | 마크다운 | 기호까지 그대로 | 가능 |
| 서식 적용 화면 | 미리보기 | 서식이 적용된 모습 | 읽기 전용 |

그 밖에 전체 복사, 탭으로 여러 메모 관리, 실시간 동기화와 자동 저장, 파일·편집·서식·보기·도움말 메뉴(찾기/바꾸기, 줄 이동, 확대·축소, 글꼴, 자동 줄 바꿈 등), 파일로 저장(.txt/.md)을 갖추고 있어요.

## 2. 파일 구성

| 파일 | 크기 | 역할 |
|---|---|---|
| `메모장-웹앱.html` | 약 101KB | **배포용 원본.** 사람들이 받아 가서 자기 계정에 게시하는 파일 |
| `메모장-체험용.html` | 약 224KB | **게시용 체험판.** 배포용 원본 + 체험용 코드 |
| `README.md` | 약 6KB | 체험판의 첫 화면 안내문이자 배포 문서 |
| `메모장-작업도구.zip` | 약 43KB | 빌드 스크립트와 테스트 도구 모음 |
| `LICENSE` | 1KB | MIT 라이선스 전문 |

체험판이 배포용의 두 배가 넘는 이유는, 배포용 원본 전체를 문자열로 품고 있다가 "앱 복제" 때 그대로 건네주기 때문이에요. 덕분에 받는 파일이 원본과 한 바이트도 다르지 않고, 배포용에는 복제 기능 코드가 한 줄도 들어가지 않아요.

**깃허브 저장소**: `https://github.com/edujoon/web-notepad`

```
web-notepad/
├── README.md              소개 문서 겸 체험판 첫 화면 안내문
├── LICENSE                MIT 라이선스
├── notepad.html           배포용 원본
├── demo/
│   └── notepad-demo.html  게시용 체험판
├── docs/
│   └── HANDOVER.md        이 문서
└── tools/                 빌드 스크립트와 테스트 도구
```

`README.md`는 저장소 첫 화면에 보이는 소개 문서이면서, 동시에 체험판의 첫 화면 안내문이에요. 고칠 때는 두 곳에서 어떻게 읽힐지 함께 생각해 주세요. 고친 뒤에는 체험판을 다시 만들어야 해요.

**게시 위치**

## 3. 체험판에만 있는 기능

체험판 맨 끝의 `<script>` 한 덩어리에 들어 있어요. 배포용에는 없어요.

- **1분마다 처음 상태로**: 메모가 안내문 한 장만 남고 나머지 탭은 저장 없이 사라져요. 여러 사람이 동시에 써도 한 창만 작업하도록 잠금을 써요.
- **앱 복제 버튼과 안내 창**: 배포용 원본 파일을 건네주고, 복제 방법을 안내해요.
- **판 번호(BUILD)**: 더 새로운 판이 돌고 있으면 오래된 창은 초기화에서 손을 떼고 "새로고침해 주세요"라고 알려요. 이게 없으면 예전 창이 옛 안내문으로 계속 되돌려써요.
- **안내문 안의 이동 링크 처리**: 배포용 앱은 제목에 이동 지점을 만들지 않아서, 체험판에서만 처리해요.

저장소 구조: `notes/demo-home`(안내문 메모), `meta/demo`(lastReset, build, readmeVersion), `meta/demo-lock`(잠금).

## 4. 수정할 때 반드시 지킬 것

1. **배포용을 고쳤으면 체험판을 다시 만들어야 해요.** `build_demo.py`를 실행하면 배포용과 안내문을 읽어 체험판을 새로 만들어요. 이 단계를 빠뜨리면 사람들이 받는 파일이 옛 버전이 돼요.
2. **안내문을 고칠 때도 다시 만들어야 해요.** `README.md`를 고치고 빌드하면 판 번호가 자동으로 올라가, 열려 있는 창이 바로 새 안내문으로 바뀌어요.
3. **게시한 뒤에는 열려 있는 창을 모두 새로고침하세요.** 휴대폰에 열어 둔 것도요. 새로고침 전의 창은 옛 코드로 동작해요.
4. **체험판을 게시할 때 기능 두 가지를 꼭 켜야 해요.** 실시간 동기화용 `db`, 파일 저장용 `downloads`예요.
5. **배포용 파일 맨 위의 제작자 표시와 라이선스 문구는 지우지 마세요.** MIT 라이선스의 조건이에요.

빌드 명령은 이렇게 써요. 스크립트 안의 경로는 실제 파일 위치에 맞게 바꿔 주세요.

```
python3 build_demo.py
```

## 5. 코드 지도 (배포용 파일 기준)

한 파일 안에 모두 들어 있어요. 찾을 때는 함수 이름으로 검색하세요.

- `stripMd(raw)` — 마크다운을 걷어 내면서, 걷어 낸 글자가 원본의 어느 위치에서 왔는지 지도를 함께 만들어요. 서식 제거 보기에서 편집이 가능한 핵심이에요.
- `mapEdit`, `resolveEdit` — 서식 제거 보기에서 한 편집을 원본에 반영해요. 여러 방식을 시도해 보고 화면과 정확히 일치하는 결과를 골라요. 굵은 글자를 덮어써도 서식이 유지되는 이유예요.
- `renderSource(raw)` — 서식 적용 보기용 전처리예요. `**'강조'**를`처럼 조사가 붙어 서식이 깨지는 한국어 문제를 여기서 해결해요.
- `makeDbStore`, `makeLocalStore` — 저장소예요. 같은 모양(subscribe/newId/save/remove)이라 다른 저장소로 갈아 끼우기 쉬워요. 실시간 저장을 쓸 수 없으면 자동으로 브라우저 저장으로 내려가요.
- `flush`, `markDirty`, `onDocs`, `applyRemote` — 저장과 동기화 처리예요.
- `openFind`, `computeMatches`, `replaceAll` — 찾기와 바꾸기예요.
- `saveOut`, `saveFile` — 파일로 저장이에요.

## 7. 확인된 제약

직접 시험해서 확인한 내용이에요. 다시 확인할 필요 없어요.

- **로그인 없이는 쓸 수 없어요.** 실시간 저장 기능을 쓰는 앱은 공개 링크로 공유할 수 없고, 열려면 로그인이 필요해요.
- **로그아웃 상태에서는 파일 저장이 동작하지 않아요.** 그래서 앱 복제 버튼이 보이지 않아요. 실제로 공개 링크를 만들어 시험해서 확인했어요.
- **메뉴의 붙여넣기는 동작하지 않아요.** 브라우저가 앱의 클립보드 읽기를 막아서예요. Ctrl+V는 정상이에요.
- **표 구조는 서식 제거 보기에서 바꾸기 어려워요.** 칸이나 줄을 바꿀 때는 마크다운 원본에서 고쳐야 해요.
- **서식 적용 화면은 읽기 전용이에요.** 편집을 넣으려면 화면을 다시 마크다운으로 되돌리는 과정이 필요한데, 원본 서식이 마음대로 바뀌고 한글 입력이 불안정해져요.
- **탭 아이콘은 넣을 수 없어요.** 게시된 앱은 claude.ai 페이지 안에서 동작해서, 탭 아이콘은 바깥 페이지가 정해요. 파일을 브라우저로 직접 열 때는 가능해요.

## 8. 남은 아이디어

- 안내문 2번 문구 다듬기. 링크를 누르면 요청 문구가 자동으로 채워지니, "아래 문장을 그대로 보내요"와 문구 상자가 지금은 조금 번거로워요.
- 배포용 앱에도 제목 이동 링크를 지원할지 결정하기. 지금은 체험판에만 있어요.
- 초기화 주기 조정. 1분은 안내문을 읽는 도중에도 되돌아갈 수 있어서, 3분 정도가 무난해요.
- 다른 서비스에서 쓰려면 저장소를 Firebase나 Supabase로 바꾸고 일반 웹사이트로 올리면 돼요. 저장소 부분만 갈아 끼우면 되도록 만들어 두었어요.
- 검토했다가 접은 것: QR 코드로 휴대폰 연결, 로그인 없이 쓰는 구경용 링크.
