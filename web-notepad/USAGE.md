# 웹 메모장 사용 가이드

마크다운이 섞인 글을 깔끔하게 읽고 편집하고 복사할 수 있는 웹 메모장이에요.

처음이라면 화면 위쪽의 **서식 적용 화면**을 눌러 보세요. 제목·목록·표가 정돈되어 이 안내를 편하게 읽을 수 있어요. 휴대폰에서는 **미리보기**라고 표시돼요.

> 이 안내도 일반 메모예요. 자유롭게 고치거나 삭제할 수 있고, 삭제한 뒤에는 새로고침해도 다시 생기지 않아요.

## 먼저 알아둘 저장 방식

- 메모는 현재 브라우저에 자동으로 저장돼요.
- 서버로 전송되거나 다른 사용자에게 공유되지 않아요.
- 같은 링크를 열어도 다른 브라우저나 다른 기기에는 메모가 나타나지 않아요.
- 브라우저의 사이트 데이터를 지우거나 시크릿 창을 닫으면 메모도 사라져요.
- 중요한 메모는 **파일** 메뉴에서 `.txt`나 `.md`로 저장해 백업해 주세요.
- ChatGPT 미리보기처럼 브라우저 저장소가 제한된 환경에서는 메모가 현재 세션에만 유지될 수 있어요. 이때는 아래 상태 표시줄에 **현재 세션에만 유지 · 창을 닫으면 사라짐**이라고 표시돼요.

## 메모 작성과 관리

- 마지막 메모 탭 바로 뒤의 **+** 버튼이나 `Alt+N`으로 새 메모를 만들어요. 탭이 많으면 탭 줄을 가로로 움직여 버튼을 찾을 수 있어요.
- 메모는 위쪽 탭으로 나뉘며, 첫 줄이 기본 탭 이름이 돼요.
- 탭을 두 번 누르면 이름을 바꿀 수 있어요.
- 탭의 **×** 또는 **파일 → 메모 삭제**로 메모를 지워요. 삭제는 되돌릴 수 없어요.
- 입력한 내용은 잠시 뒤 자동으로 저장돼요. 아래 상태 표시줄에서 저장 상태를 확인할 수 있어요.

## 세 가지 보기

| 보기 | 모바일 이름 | 표시 방식과 복사 결과 | 편집 |
|---|---|---|---|
| **서식 제거 텍스트** | 텍스트 | 마크다운 기호를 숨긴 깔끔한 글 | 가능 |
| **마크다운 원본** | 마크다운 | 서식 기호를 포함한 원문 | 가능 |
| **서식 적용 화면** | 미리보기 | 제목·굵게·목록·표 등을 적용한 화면 | 읽기 전용 |

**서식 제거 텍스트**에서 글을 고쳐도 원본의 서식은 가능한 한 유지돼요. 표의 칸이나 줄처럼 구조를 바꿀 때는 **마크다운 원본**에서 편집하는 것이 안전해요.

## 마크다운 예시

아래 예시를 새 메모의 **마크다운 원본** 화면에 붙여넣고 세 가지 보기를 비교해 보세요.

```markdown
# 회의 메모

## 오늘 할 일

- **중요한 항목** 확인
- [ ] 자료 정리
- [x] 일정 공유

| 담당 | 작업 |
|---|---|
| 민지 | 초안 작성 |
| 준 | 최종 검토 |

자세한 내용은 [프로젝트 저장소](https://github.com/edujoon/web-notepad)에서 확인하세요.
```

## 전체 복사와 파일 저장

- **전체 복사**는 현재 선택한 보기 방식대로 메모 전체를 복사해요.
- 서식 없이 붙여넣으려면 **서식 제거 텍스트**에서 복사하세요.
- 제목·굵게·표 모양을 유지하려면 **서식 적용 화면**에서 복사하세요.
- **파일 → 서식 제거 텍스트로 저장 (.txt)**은 글자만 저장해요.
- **파일 → 마크다운 원본으로 저장 (.md)**은 마크다운 구조를 그대로 저장해요.
- **파일 열기**로 `.txt`, `.md`, `.markdown` 파일을 새 메모로 가져올 수 있어요.

## 나만의 앱 만들기

화면 오른쪽 위의 **앱 복제**를 누르면 이 메모장과 같은 기능을 가진 앱을 ChatGPT 안에서 바로 실행할 재료를 가져갈 수 있어요. 주소만 공유하는 기능이 아니라, Canvas 또는 HTML·React 미리보기를 만들 자체 포함 앱 소스와 제작 요청문을 함께 준비해 줘요.

1. **코드와 프롬프트 복사**를 누르거나 **복제 파일 다운로드**로 파일을 받으세요.
2. **ChatGPT 열기**를 눌러 새 대화를 열고 내용을 붙여 넣거나 파일을 첨부하세요.
3. 앱 미리보기를 생성해 달라고 요청하세요. 별도 배포 안내나 설정 질문보다, 원본 설정으로 조작 가능한 미리보기를 먼저 만들도록 요청문이 들어 있어요.

내용이 길어 복사되지 않으면 **복제 파일 다운로드**로 UTF-8 텍스트 파일을 받은 뒤 ChatGPT 대화에 첨부하세요. 파일 안에는 제작 요청문과 실행 가능한 단일 HTML이 명확한 경계로 나뉘어 들어 있어요. 복제 HTML은 기본 사용 가이드, 마크다운 처리와 HTML 정화 라이브러리를 포함하고 시스템 글꼴을 사용하므로 원본 사이트에 다시 접속하지 않아도 실행할 수 있어요.

> 내가 작성하거나 이름을 바꾼 메모, 브라우저에 저장된 데이터와 화면 설정은 복제 자료에 포함되지 않아요. 새 사용자를 위한 이 기본 가이드, 마지막 탭 뒤의 + 버튼, 📋 파비콘과 앱 복제 기능은 새 앱과 그 앱에서 다시 만든 복제 자료에도 포함돼요.

ChatGPT 미리보기에서 저장소·클립보드·다운로드 권한이 제한되면 해당 기능만 사용할 수 없다는 안내가 나와요. 메모 편집, 탭 전환과 마크다운 미리보기는 계속 사용할 수 있고, 영구 저장이 되지 않을 때는 저장됐다고 표시하지 않아요.

## 편집 도구

- **편집** 메뉴에서 실행 취소, 다시 실행, 찾기, 바꾸기, 줄 이동을 사용할 수 있어요.
- **서식** 메뉴에서 자동 줄 바꿈과 기본/고정폭 글꼴을 선택할 수 있어요.
- **보기** 메뉴에서 확대·축소와 상태 표시줄 표시 여부를 바꿀 수 있어요.
- 메뉴의 붙여넣기가 브라우저 보안 설정에 막히면 `Ctrl+V` 또는 `⌘V`를 사용하세요.

## 제한 사항

- Vercel에 배포된 웹 메모장은 브라우저 로컬 저장 방식이라 기기 간 동기화를 제공하지 않아요.
- 메모 하나는 저장 데이터 기준 약 250KB까지 지원해요. 전체 저장 공간은 브라우저의 localStorage 한도를 따라요.
- 서식 적용 화면은 읽기 전용이에요.
- 원본 Vercel 화면은 외부 글꼴과 CDN 라이브러리를 사용하지만, 앱 복제 자료는 시스템 글꼴과 내부에 포함된 라이브러리를 사용해요.
- ChatGPT에서 Canvas 또는 HTML·React 미리보기를 제공하는지는 사용 중인 계정과 환경에 따라 다를 수 있어요. 미리보기를 만들 수 없는 환경에서는 완료됐다고 가정하지 말고 제한 안내를 확인해 주세요.
